Architecture & Optimizations

01. PRE-RESIZING
Aspect-Ratio Scale

OpenCV resizes frames before model evaluation, projecting bounding box coordinates accurately back to original image space.

02. RING BUFFER
Lock-Free Queues

Depth-1 input queue drops stale frames, preventing queue latency and ensuring high FPS streaming on CPU.

03. WEBSOCKET PIPELINE
Full-Duplex WS

Binary JPEG frames stream up while JSON detection metadata and base64 rendered frames stream down continuously.

04. THRESHOLD TUNING
Interactive Sliders

Dynamic Confidence and IoU threshold controls update backend inference filters instantly without reloading.
